# AI-Driven Telegram Web App: Интерактивный трекер привычек с геймификацией ❄️🔮⚡

Профессиональный Full-Stack проект, разработанный в рамках интенсивного челленджа **Winter Arc 2026**. Приложение представляет собой интерактивный трекер личной эффективности, полностью интегрированный в мессенджер Telegram в формате **Telegram Mini App (Web App)**.

* **Действующий бот в Telegram:** [@vinnikova_arc_bot](https://t.me)
* **Инфраструктура деплоя:** Replit Cloud PaaS (2 vCPU / 4 GB RAM)
* **Интерфейс:** Кастомная неоновая тема оформления (Cyberpunk Neon UI)

---

## 🎯 Продуктовая концепция & Бизнес-логика
* **Проблема:** Высокий процент «выгорания» и потеря фокуса пользователями на длительных марафонах саморазвития из-за отсутствия быстрой дофаминовой отдачи.
* **Решение:** Инструмент контроля дисциплины, минимизирующий когнитивную нагрузку при фиксации ежедневных рутинных действий (ввод в 1 клик внутри мессенджера) и использующий геймификацию. Выполнение каждой привычки начисляет пользователю **10 XP** один раз в день, исключая возможность «фарма» очков через повторные клики.
* **Целевая аудитория:** Профессионалы, проходящие интенсивные технические челленджи, требующие ежедневного трекинга прогресса.

---

## 🛠️ Стек технологий и Архитектура

Проект спроектирован с упором на асинхронность, высокую скорость отклика и экономное потребление ресурсов серверного контейнера (RAM < 450MB):

* **Backend / Асинхронное ядро:** Python 3.11, **aiogram 3** (индустриальный стандарт асинхронной интеграции с Telegram Bot API), **FastAPI** (высокопроизводительный веб-сервер для обработки REST API запросов фронтенда).
* **Параллелизация процессов:** Конкурентный запуск FastAPI и aiogram 3 внутри единого event loop в рамках одного процесса с помощью встроенной библиотеки `asyncio`.
* **База данных / ORM:** SQLite (хранилище данных в локальном файле `tracker.db`), **SQLAlchemy** (ORM-система для абстракции над SQL-запросами, изоляции бизнес-логики и построения реляционных моделей данных).
* **Фронтенд:** Чистый JavaScript (Vanilla JS), HTML5, кастомный адаптивный CSS3 (Cyberpunk Neon). Для безопасности в продакшене используется строгая валидация подписи Telegram Mini App (`initData`), а для локальной разработки предусмотрен демо-режим.
* **ИИ-Модуль (AI-Driven):** Интеграция с **Anthropic Claude API**. Реализован фоновый асинхронный процесс, который агрегирует логи активности пользователя за последние 7 дней, вычисляет эффективность и формирует текстовый психологический разбор недели с отправкой в чат.

## 📂 Структура репозитория

* `main.py` — Главная точка входа, конфигурация event loop, асинхронный запуск веб-сервера и Telegram-бота на одном порту (по умолчанию `8000`).
* `database.py` — Настройка сессий SQLAlchemy, описание моделей данных (`Users`, `Habits`, `DailyLogs`, `WeeklyReports`).
* `bot.py` — Обработчики команд мессенджера (`/start`, `/weekly`), логика инлайн-клавиатур, интеграция с Web App.
* `api.py` — Маршруты (эндпоинты) FastAPI для асинхронного обмена данными между интерфейсом и базой данных, валидация `initData`.
* `static/` — Статические ресурсы: скрипты JavaScript (асинхронные fetch-запросы) и файл `style.css` (кастомная киберпанк-палитра).
* `templates/` — HTML-шаблон дашборда для отрисовки внутри встроенного браузера Telegram.

## 💻 Локальное развертывание проекта (Quick Start)

Для управления зависимостями и быстрой сборки проекта используется современный и сверхбыстрый менеджер пакетов **uv** от Astral.

1. Клонируйте репозиторий и перейдите в папку проекта.
2. Создайте файл конфигурации окружения на основе шаблона:
   ```bash
   cp .env.example .env
   ```
3. Заполните переменные в `.env` (токен бота, ключ Anthropic API и публичный HTTPS URL вашего Web App в переменной `TELEGRAM_WEBAPP_URL`). **Важно:** никогда не отправляйте файл `.env` в коммиты Git.
4. Запустите проект одной командой:
   ```bash
   uv run python main.py
   ```
